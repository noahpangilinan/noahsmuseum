# Noah's Museum

A virtual museum you can walk through in the browser, built with [Three.js](https://threejs.org/).

**Visit it at [noahsmuseum.netlify.app](https://noahsmuseum.netlify.app).**

Wander the rooms in first person, sit on the benches, and click a painting to read its label or look closer.

| Control | Action |
| --- | --- |
| Click | Enter the museum |
| W A S D | Walk |
| Mouse | Look around |
| Shift | Run |
| C | Crouch |
| M | Map (click a spot to teleport there) |
| Click a bench | Sit down |
| Click a painting | Show its label, or magnify it |
| Esc | Release the mouse |

Works best in a desktop browser with a mouse and keyboard.
